# Organization-Wide Notes

Use this file for durable guidance that should be injected into every Agentic
Researcher agent launched by this org.

Good examples:

- Where shared datasets, caches, or scratch directories live.
- Which internal services, schedulers, or GPU backends are preferred.
- Security or privacy rules that apply to all projects.
- Cross-project conventions for reporting reusable lessons.

Avoid project-specific experiment results here. Put those in the project's
Agentic Notes records on `agentic/project-records`.
